# Rare Earth Web App

Welcome to the Rare Earth web application!  
This project is built with [Laravel 12](https://laravel.com/) and [Inertia.js](https://inertiajs.com/).

## Getting Started

1. **Clone the repository**
2. **Install dependencies**
    ```bash
    composer install
    npm install
    ```
3. **Environment setup**
    - Copy `.env.example` to `.env` and update settings as needed.
4. **Run migrations**
    ```bash
    php artisan migrate
    ```
5. **Start development server**
    ```bash
    php artisan serve
    npm run dev
    ```

## Testing

Run tests with Pest:
```bash
php artisan test --compact
```
